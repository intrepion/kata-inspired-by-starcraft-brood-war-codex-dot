# Cinder Relay specification
Delegated choices, 2026-10-12. No interactive interview occurred. Design frontier settled using the user's authorization.
A compact top-down RTS on the basalt moon Aster: the Lumen Expedition fights the autonomous Hollow Array over an ancient relay. One playable faction; AI uses the same economy and roster, with a distinct aggressive doctrine and rust palette. Original geometric art and procedural audio.
Workers gather finite ore and return cargo to a core. Workers construct foundries, supply pylons and defensive sentries. Pay once; invalid placement pays nothing; cancellation returns 75% of construction or queued unit cost. Completed structures are not refundable. Foundries queue up to five combat units; cores queue workers. Reserve supply on enqueue. Unit roles: Dart skirmisher counters Mortar; Bulwark armor counters Dart; Mortar siege counters Bulwark and buildings. Structures obstruct navigation; units separate locally. Unreachable orders fail clearly.
Hold the central relay uncontested with combat units for 60 seconds or destroy the enemy core to win. Loss of own core means defeat. Pause freezes simulation. Retry creates fresh state. Save/reload resumes pending orders, queues, economy and relay. Replay plays the last match command log from initial state. Training has slower AI; Standard is the default intended opponent.
Selection by click/drag, Shift additive, right click context orders, A attack-move, S stop, 1 select army, W select workers, Escape cancel/pause. Context commands have visible buttons. Responsive desktop layout; small screens may scroll. Touch and physical audio are not claimed verified.
Public test seams: match creation, command submission, fixed simulation step, save/load and replay. Browser seam: visible UI controls and canvas pointer input. These seams are chosen under delegated test-design authorization.
